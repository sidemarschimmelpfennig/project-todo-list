# Project TodoList

## Setup

Make sure to install dependencies:

```bash
# npm
npm install

# pnpm
pnpm install

# yarn
yarn install

# bun
bun install
```

## Development Server

Start the development server on `http://localhost:3000`:

```bash
  # npm
  npm run dev
```

Start Start the development server json

```bash
  #npm
  npm run backend
```

## Production

Build the application for production:

```bash
# npm
npm run build
```
